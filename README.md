# 🎃 MAOU Halloween Prompt Maker

**日本語・英語対応のハロウィン画像生成プロンプトメーカー。**  
画像生成の専門用語がわからなくても、選択肢を組み合わせてプロンプトを作れます。

A free, bilingual (Japanese / English) prompt generator for Halloween-themed AI images. No API key required.

## ✨ 特徴 / Features

- 🎭 主役、仮装、背景、動き、画風、雰囲気、照明、構図などを選択
- 🎲 ランダム生成で思いがけない組み合わせを発見
- 🖼️ 画像の縦横比・サイズ指定や自由入力に対応
- 📖 **72種類の構図解説**で、遊びながら画像表現を学べる
- 🌐 日本語 / English の表示とプロンプトに対応
- 📋 ワンクリックでプロンプトをコピー
- 🌙 ダーク / ライトモード切替
- 🚫 画像内の文字を避けるための指示に対応
- 🔒 APIキー不要。単体のHTMLファイルで動作

## 🚀 使い方 / How to use

1. このリポジトリの `index.html` をダウンロードします。
2. ファイルをブラウザで開きます。
3. 好きな項目を選ぶか、ランダム生成を試します。
4. 出力されたプロンプトをコピーして、お使いの画像生成AIに貼り付けます。

**English:** Download `index.html`, open it in a browser, choose your options (or randomize), then copy the generated prompt into your preferred image-generation tool.

> **注意 / Note:** 画像生成AIによって、画面比率・ピクセルサイズ・文字なし等の指示が正確に反映されない場合があります。生成結果は利用するAIの仕様にも左右されます。  
> Image generators may not follow aspect ratio, exact pixel dimensions, or no-text instructions perfectly.
